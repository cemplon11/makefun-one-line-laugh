One funny line for make.fun's "The One-Line Laugh" bounty: a single sentence of
at most 200 characters, judged two at a time by a house judge that keeps the
bigger laugh. `main.py` (pure Python stdlib, deterministic, no network) writes
the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
